# Security Policy

## Scope

This repository is an open-source research and engineering project. Security reports should describe the affected component, the tested commit or version, prerequisites, reproduction steps, impact, and a minimal proof of concept that does not expose credentials or harm third-party systems.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Use GitHub's private vulnerability reporting feature when available, or contact the maintainer through the verified project profile.

Do not test against the hosted demo, production services, real user data, or third-party infrastructure without explicit permission.

## Disclosure

The maintainer will acknowledge valid reports, investigate them, coordinate a fix where practical, and agree on a responsible disclosure timeline with the reporter. Public write-ups must remove private data, credentials, sensitive infrastructure details, and weaponized exploit instructions.

## Safety note

The observatory aggregates satellite detections, citizen reports, and AI-assisted signals. These signals require human verification and must not be treated as guaranteed emergency or evacuation advice.
